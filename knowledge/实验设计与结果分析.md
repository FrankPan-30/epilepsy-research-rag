# 实验设计与结果分析
来源类型：项目工作规则；不是已完成实验。

实验记录包括：问题、假设、竞争解释、预期现象、基线、单一改动、数据版本、划分、随机种子、代码版本、运行配置、评价与报警规则、结果路径、状态。

参数在训练/验证数据上选择。外层测试用于最终评价。比较模型时保持患者/发作划分、数据时长和报警协议一致。实验单位应按研究设计说明，重叠窗口不当作独立患者样本。

报告窗口与事件两组指标；同时呈现患者/发作层面分布、效果量和不确定性。统计方法取决于独立单位和配对结构，应先检查原始结果再指定。

阴性结果、失败尝试、偏离计划、运行错误都应保存。区分重新训练的结果与从旧预测重新计算的指标。

建议输出：方案 → 依据 → 唯一改动 → 评价指标与成功判据 → 可能反例 → 下一步。假设与实测结果严格分栏。
